# AUDIT: CONFIG & API

Прочитані файли:
js/config.js
js/api.js

Підтверджені факти:
- js/config.js містить центральну конфігурацію сайту (GAS URL, соцмережі, розміри, кэш).
- js/api.js відповідає за завантаження каталогу, кеш, нормалізацію товарів, мережеві запити та аналітику.
- Поточні джерела каталогу: data/products.json (пріоритет), data/products_auto.json (резерв), Google Apps Script (fallback).
- Роль кешу: localStorage використовується для швидкого завантаження.
- Роль GAS: використовується як fallback для каталогу та endpoint для POST-операцій.
- Роль products_auto.json: резервне джерело товарів.
- Роль extra_photos.json: доповнення фотографій товарів.
- Залежності CFG та S: CFG надає константи для роботи системи та ініціалізації стану.

Підтверджені технічні ризики:
- Використання локального кешу може призвести до застарілих даних, якщо TTL не відповідає частоті оновлень.
- Позалежність від GAS як fallback може впливати на швидкість завантаження при відсутності локальних даних.

HYPOTHESIS:
- localStorage теоретично може мати обмеження при великому кеші, але проблема переповнення не підтверджена runtime-тестом.
- Точна поведінка S, getCatalog, renderHome і renderCatalog потребує читання інших файлів.
