# SUPER WOW.ZNAHIDKA

Мета:

перетворити WOW.ZNAHIDKA на преміальний sneaker-discovery application, який допомагає знайти свою пару швидше, цікавіше та персональніше за звичайний каталог.

Головна ідея:

Свайпай.
Лайкай.
Знаходь свою пару.

Майбутні напрями:

1. WOW Match 2.0

Персональні рекомендації на основі реальних даних:

стать;
розмір;
бюджет;
кольори;
стиль;
бренди;
лайки;
пропуски.

2. Style Finder

Короткий сценарій:

розмір;
бюджет;
стать;
стиль;
кольори;
персональна добірка реальних товарів.

3. WOW Style DNA

Персональний sneaker-профіль із можливістю поділитися.

4. WOW Battle

Порівняння двох реальних моделей.

5. Майбутня інтеграція з WOW OS.

Принципи:

не використовувати слово Tinder у публічному продукті;

не вигадувати товари або характеристики;

не працювати прямо у main;

не ламати production;

не змінювати парсери;

не змінювати формулу цін;

не змінювати токени;

не змінювати Telegram sessions;

не змінювати товарний pipeline без окремого архітектурного рішення;

не обирати React або Next.js тільки через популярність;

спочатку дослідити поточну архітектуру.
